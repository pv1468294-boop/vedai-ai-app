# Vedai Mobile Application

React Native mobile app for Vedai AI Assistant.

## Getting Started

```bash
npm install
npm start
```

## Running on Platforms

```bash
# iOS
npm run ios

# Android
npm run android

# Web
npm run web
```

## Features

- 🔐 Email/Password Authentication
- 🔵 Google Sign-In
- 👍 Facebook Login
- 💬 Real-time Chat
- 🎤 Voice Features (TTS/STT)
- 📱 Cross-platform (iOS, Android, Web)
